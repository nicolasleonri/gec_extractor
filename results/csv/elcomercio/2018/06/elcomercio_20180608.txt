## News Paper Content Parser

This repository contains code for parsing textual contents out of scanned images of newspapers using Optical Character Recognition (OCR) tools such as Google Cloud Vision API and AWS Textract. It also includes scripts for cleaning up extracted texts and converting them into structured formats like CSV files or JSON arrays.

### Prerequisites:

To run these scripts successfully, make sure you have installed Python along with necessary libraries including `google-cloud-vision`, `awscli` and others mentioned within individual script comments.

### Usage Instructions:

#### Step 1: Set Up Environment Variables

Before running any script related to cloud APIs, ensure environment variables required for authentication purposes are correctly configured according to respective documentation provided by those platforms.

For instance,

```
GOOGLE_APPLICATION_CREDENTIALS="/path/to/google_credentials.json"

AWS_ACCESS_KEY_ID="your_access_key_id_here"
AWS_SECRET_ACCESS_KEY="your_secret_access_key_here"
REGION_NAME="eu-west-1"
BUCKET_NAME="my_bucket_name"
FILE_PATH_IN_BUCKET="folder/file.pdf"
OUTPUT_FILE_NAME="output.csv"
```

Replace placeholders accordingly based upon what's applicable for your setup.

Depending on whether you're dealing with PDF documents stored in Amazon S3 buckets or scanning physical copies through mobile devices before uploading their scans online, select appropriate scripts listed under different sections (`pdf_to_csv.py`, `mobile_scanner_app.ipynb`) etc., following detailed usage notes included therein.
