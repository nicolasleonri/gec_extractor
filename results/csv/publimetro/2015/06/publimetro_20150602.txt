En años recientes, la industria alimentaria ha añadido estas bacterias buenas en varios productos, desde yogurt hasta fermentos lácteos con el objetivo de mejorar el tránsito intestinal y el sistema inmunitario.\nNuevas propiedades\nLos probióticos están teniendo gran éxito comercial actualmente. Su consumo generaría ganancias superiores a $31 mil millones de dólares en todo el mundo. Además, la investigación científica respecto a sus beneficios continúa vigente. Actualmente se estudia cómo podrían contribuir a reducir la acumulación de grasas corporales y también se descubrió recientemente una bacteria japonesa que ayuda a combatir enfermedades gastrointestinales tales como diarrea y flatulencias.\nPúblico meta\nYa hemos comentado previamente que los probióticos son organismos vivos. Así entonces, resulta fundamental mantener correctamente conservados aquellos productos que incluyen dichas bacterias. \"Si compras un yogurt que ha permanecido fuera de una nevera o mucho tiempo expuesto al calor ambiente probablemente no posea bacterias probióticas, dado que habrá muerto\", aclara Hurtado.\nOrigen\nEsta moda comenzó en Japón en 1930 cuando el investigador Minoru Shirota cultivó exitosamente una bacteria para facilitar la digestión humana. Ésta la denominó Lactobacillus casei shirota. Mediante dicho organismo lanzó el primero de muchos alimentos funcionales conocidos hoy en día como Yakult. Esta bebida es el alimento funcional más vendido en el mundo entero.\nCómo operan dentro del cuerpo humano\nActúan directamente sobre la membrana interna del tracto gastrointestinal optimizando así la composición natural de nuestra microbiota intestinal además de estimular nuestro propio sistema inmunitario mediante la producción de anticuerpos específicos contra patologías víricas y bacteriológicas nocivas para nosotros mismos. Otros tienen capacidad para mitigar síntomas asociados a gripes y resfríos habituales. Todo dependerá siempre del tipo particular de bacterias consumidas junto con la cantidad total suministrada.\nDatos relevantes\nActualmente existe muchísima información disponible referente a los probióticos tanto en internet como en revistas especializadas dedicadas exclusivamente a temas relacionados con la medicina alternativa y/o complementaria.\nMercado peruano\nAquí en Perú aún estamos incipientes en cuanto a ventas de productos probióticos puesto que apenas capturan entre el 2% y el 4% del sector lácteo nacional.\n¿El yogurt es un probiótico?\nNo necesariamente. Posteriormente mezclaremos todos nuestros ingredientes sólidos excepto el endulzante elegido en un recipiente amplio apto para hornear colocándolo encima de una mesa resistente. # Newspaper Article Extraction Tool

This tool extracts structured data from scanned images of newspapers using Optical Character Recognition (OCR) technology. It processes input files provided via command-line arguments and outputs extracted information in either CSV format for tabulated data like sports results or JSON format for narrative texts such as news stories.

## Features:

- **Input Handling**: Accepts file paths through CLI options (`--input` or `-i`) which may include wildcards (*) for batch processing.
  
- **Output Specification**: Allows specifying the desired output directory (`--output-dir`, default `./outputs`). Supports both `.csv` and `.json` formats based on detected table structures within pages.
  
- **Format Detection**: Automatically detects whether each processed page contains tabular data suitable for CSV export or requires conversion to JSON for textual narratives.
  
- **Error Management**: Implements robust exception handling during parsing operations ensuring graceful degradation upon encountering malformed inputs.
  
- **Logging**: Provides detailed logging capabilities controlled via verbosity levels (-q for quiet mode up to --debug level logs every step taken by parsers).

### Usage Example:

To process a series of PDF documents located under `/path/to/documents/*.pdf` extracting their contents into respective directories named after each document’s basename but suffixed with `_extracted_data`, run:

```
python newspapelextract.py \
-i /path/to/documents/*.pdf \
-o ./documents_extracted_output_dir \
-v INFO
```

The above command specifies verbose informational messages about its operation while directing it towards scanning specified pattern-matched PDF files found within given path(s), subsequently organizing resulting extractions neatly according to predefined naming conventions alongside chosen destination folder structure.

Note: This script assumes Python environment setup along necessary dependencies installed including libraries capable of performing OCR tasks effectively across various languages supported by underlying models used herein (like PyMuPDF for PDF manipulation etc.).
